## 메모

- 요율 확인(2026): 국민연금 9.5%(근로자 4.75%), 건강보험 7.19%(근로자 3.595%), 장기요양 건보료의 13.14% — 여러 검색결과 일치, 코드 유지. 국민연금 기준소득월액 상·하한 2026.7~2027.6: 41만~659만원(뉴스 다수 일치) 추가. 과거 연도 요율(2021~2023 건보·장기요양)은 기억에 의존, 원문 미대조.
- 원천징수영수증: 서식 개정일은 2021.3.16, 2023.3.20(8쪽), 2025.3.21(9쪽), 2025.6.30, 2026.3.20(9쪽)만 검색으로 확인. 2024.3.22는 미확인(공통지침 예시값). 제1쪽 행 구성(⑮-1~⑮-4, ⑱·⑱-1·⑱-2·⑱-4·⑲·⑳·⑳-1, ④ 주민등록번호, ③-1/③-2, 종교관련종사자 여부)과 Ⅲ 번호 (72)~(76)은 기억 기반이라 원본 대조 필요. 식사대 P01 행 번호는 확인 못해 번호 없이 표기. 귀속연도 표기 위치도 미확인.
- 소득금액증명: 2022.9.22 1종 통합은 확인. 단 '종합소득세 신고 현황' 표의 정확한 열 구성은 미확인(상호·사업자등록번호·수입금액·소득금액으로 가정).
- 국민연금 가입증명: 별지 제11호서식 제목·인적사항 항목은 확인, 개정일과 기준소득월액 열의 실제 존재 여부는 미확인(현행 유지).
- 건강보험 자격득실 확인서: 가입자구분 세분값(지역세대주/세대원, 직장피부양자)과 증명 문구는 미확인.
- 부채증명서: 은행별 열 구성 확인 불가로 보류. 원본 이미지 확보 시 과목·약정금액·이율·연체 표시 방식 재검토.
- 통장사본·거래내역확인서·잔액증명서·카드명세서는 은행·카드사마다 양식이 달라 통용 항목 수준으로만 맞춤.
