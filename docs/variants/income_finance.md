# 소득·금융 서류 변형 목록 (income_finance)

직장 이력은 `_work_history(p, many)` 에서 **프로필 단위로** 정한다 (`many=True` 는 이직이 잦은 사람, 별도 시드).
그래서 같은 고객이면 국민연금 가입증명·건강보험 자격득실·소득금액증명·원천징수영수증의 이전 직장 이름·기간이 서로 맞는다.
육아휴직 기간은 `_leave_period(p)` 로 프로필마다 하나 정해, 재직증명서·경력증명서·건강보험료 납부확인서가 같은 기간을 쓴다.
`_ensure_gap(hist, kind)` 는 특수 상황에서 지역가입자/피부양자 공백이 없을 때 이전 직장 하나의 끝을 당겨 공백을 만든다.

맺음말·발급기관·직인 블록은 `<div class="keep">`(flex) 로 묶어 쪽 나눔에서 쪼개지지 않는다 (직인만 앞 쪽에 남는 문제 방지).
