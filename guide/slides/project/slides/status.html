검증한 것과 아직인 것

검증함

  • 예전 1부 OCR 학습: 서버에서 학습 완료
  • 생성기·studio·학습 테스트 통과 (python -m pytest, GPU 없이)
  • 학습 실행: 가짜 학습 도구로 전체 실행, 합친 채점 = 예전 채점
  • 채점기에 정답을 넣으면 모든 과제 100점
  • studio ⑥·⑦: OCR·업무 문항을 한 화면에서 보기·채점

아직

  • 섞은 데이터로 한 실제 GPU 학습 결과
  • 실제 서류 묶음으로 한 은행 업무 평가
  • OCR 사람 검수 정답셋

서버에서 겪은 이슈

  • OCR 데이터 경로 오류 → 실행 전 경로 일괄 검사 추가
  • A100 40GB 메모리 부족 → 비전 인코더 고정 + zero3 설정 추가

현재 상태 · 학습 결과가 나오면 점수표 슬라이드를 추가

OCR과 은행 업무 학습을 하나로 합쳤고, 섞은 데이터로 한 학습 결과는 아직입니다. 처음 돌리면서 경로 문제와 40GB GPU 메모리 문제를 만나 고쳤고, 결과가 나오면 이 다음에 점수표 슬라이드를 넣겠습니다.
