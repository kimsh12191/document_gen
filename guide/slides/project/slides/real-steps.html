실제 데이터로 확장

처음부터 학습 데이터를 실제로 바꾸려 하기보다, 실제 서류 묶음 수십 개로 평가 세트를 먼저 만드는 걸 권합니다. 합성으로 학습한 모델이 실제 서류에서 얼마나 되는지가 지금 가장 궁금한 숫자이기 때문입니다. prepare가 정답을 넣었을 때 만점이 나오는지 검사하므로, 정답이나 eval을 잘못 적으면 여기서 걸립니다.
