1부 OCR · 데이터 구조

입력: 이미지 + OCR JSON → manifest 한 장

① 사내 OCR 결과 (페이지마다 JSON)

{"success": "Y",
"data": {"basicData": [[
{"text": "2024", "confidence": 0.9999,
"bounding": {"vertices": [
{"x":140,"y":46}, … 4점]}}
]]}}

미리 돌려 둔 JSON을 그대로 씀. 없으면 prepare가 사내 OCR 호출 후 캐시

② manifest.jsonl (페이지마다 한 줄)

{"document_id": "doc123",
"page_id": "p001",
"image": "/data/doc123_p001.png",
"ocr_json": "/ocr/doc123_p001.json",
"split": "train"}

bank_ocr scan이 폴더를 훑어 만듦. 파일명 정규식으로 문서 ID 추출

문서 ID가 핵심: 분리를 문서 단위로 해서 같은 문서의 쪽들이 학습과 평가에 갈라지지 않게

실제 데이터는 이 두 가지만 있으면 됩니다. 페이지 이미지와, 그 이미지를 사내 OCR에 돌린 JSON입니다. scan 명령이 이 둘을 짝지어 manifest를 만들고, prepare가 manifest를 읽습니다.
