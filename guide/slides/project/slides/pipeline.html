두 단계 모두 같은 파이프라인, 한 명령

prepare

학습 형식으로 변환·검사

eval_base

출발 모델 평가

sft

LoRA 학습

eval_sft

평가 + GRPO 후보 풀기

select

틀린 문제 위주 선정

grpo

SFT에서 이어 학습

eval_grpo

GRPO 평가

report

비교표

실행

python run_pipeline.py --config configs/pipeline.json
python run_bank_pipeline.py --config configs/bank_pipeline.json
# --smoke 리허설 · --from grpo · --only report

공통 설계

  • 단계마다 state.json에 기록, 멈추면 같은 명령으로 이어서
  • 평가: GPU마다 vLLM 서버 1개, LoRA는 병합해서 서빙
  • Base·SFT·GRPO가 같은 문항·이미지·설정으로 풀어야 비교표 생성
  • 2부는 1부 코드를 상속, 데이터·채점·보고서만 교체

전체 그림

두 파이프라인 모두 prepare부터 report까지 여덟 단계를 한 명령으로 돕니다. 각 단계가 끝나면 state.json에 기록하므로 중간에 멈춰도 같은 명령으로 이어집니다. eval_sft에서 SFT 모델 서버를 띄운 김에 GRPO 후보 문제도 같이 풀어 두고, select에서 SFT가 틀린 문제를 골라 GRPO를 합니다.
