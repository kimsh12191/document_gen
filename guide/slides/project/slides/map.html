왜 두 갈래 데이터인가

업무 판단은 결국 서류를 정확히 읽는 것 위에서 돈다. 읽기는 실제 서류로, 판단은 정답을 마음대로 만들 수 있는 합성 서류로. 학습은 섞어서 한 번.

모델과 도구

Qwen3.5-9B + LoRA, ms-swift 4.x 학습, vLLM 평가 서버. A100 2장(80GB / 40GB 설정 각각).

전체 그림

OCR 과제는 내부망에서 실제 서류 이미지를 사내 OCR로 돌린 결과를 정답 삼아 읽기 능력을 가르칩니다. 은행 업무 과제는 합성 서류로 업무 판단을 가르칩니다. 두 데이터셋을 섞어 한 번에 학습합니다. 예전에는 OCR 학습(1부) 뒤 그 모델에서 은행 업무 학습(2부)을 했습니다. 합성 서류는 정답과 불일치를 우리가 직접 만들 수 있다는 게 핵심입니다.
