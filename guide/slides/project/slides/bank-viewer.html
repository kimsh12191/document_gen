학습으로 좋아진 문제만 골라 본다

bash viewer/bank_start.sh # 저장된 답만 (GPU 불필요)
bash viewer/bank_start.sh runs/bank1/merged/<모델> 1 # + 직접 테스트 · http://localhost:7861

벤치마크 보기

  • 모델별 답을 정답과 나란히, 항목별 초록(맞음)·빨강(틀림)
  • 서류 이미지는 모델이 본 크기 그대로, 서류 이름·쪽·변조 사본 표시
  • 과제·업무·불일치 사례·심사 능력으로 거르기
  • “SFT는 맞히고 출발 모델은 틀린 문제”처럼 좋아진·나빠진 문제만
  • 지금 모델로 다시 풀어 보기

직접 테스트

  • 내 서류(이미지·PDF)를 올려서
  • 서류 구비 확인 · 서류 대조 · 심사 질의 · 정보 추출 · 분류 · 받아쓰기
  • 학습한 질문 문장과 이미지 크기 규칙 그대로 → 학습 형식대로 답이 나옴
  • 업무를 고르면 필수 서류 목록 자동 입력
