결과 보기 · studio ⑦ 평가

모델끼리, 데이터셋끼리 한 표로 비교

python -m train … 이 끝나면 평가 세트마다 모델 답이 자동으로 붙음 (GPU 불필요)
studio ⑥ 학습 → train/configs/studio-<이름>.json 내보내기 · 실행 명령 · 진행(state.json)

⑦ 평가

  • 고른 데이터셋들의 채점 결과를 벤치마크별 한 표로
  • 모델·버전끼리 비교
  • 합성 / 실서류, 의사정답 / 검수 정답 구분
  • OCR · 문서 이해 · 업무 처리 과제 묶음별
  • 명령줄 보고서(benchmark.html)와 같은 채점기

⑥ 학습 설정 내보내기

  • 학습 데이터셋 여러 개 (OCR·문서·업무), 데이터셋마다 문항 수
  • 평가 세트 여러 개
  • path_map으로 학습 컨테이너 경로로 바꿔 씀
  • python -m train --config train/configs/studio-<이름>.json

결과 보기 · 읽는 법: guide/results.md · guide/training.md

평가 화면은 GPU가 필요 없어서 학습 중에도 띄울 수 있습니다. 점수가 이상한 칸은 ⑥의 문항 탭에서 점수 낮은 문항부터 실제 답을 봅니다. 예전 은행 업무 viewer의 직접 테스트는 없어졌습니다.
