키뜻
required필수 서류 목록 (질문에 번호로 나열한 것)
names모델 답의 서류명을 대응시킬 후보: 필수 서류 + 끼워 넣은 서류
documents질문에 보여 준 서류명 (모델 답의 document 를 이 중 하나로 대응시킴)
answer_type`number` 숫자 / `yesno` 예·아니오
tol숫자 답의 허용 오차 (질문에 적은 반올림 자릿수에 맞춤)
days유효기간 문항: 발급일부터 신청일까지 일수 (정답 계산 근거)
fields키마다 `type`(값 타입), `norm`(정규화 값: 날짜 YYYY-MM-DD, 금액 정수 …), `kind`(값 종류). 타입별로 표기 차이를 맞춰 비교
types키마다 `checkbox` / `checkbox_multi` / `seal` / `signature`
