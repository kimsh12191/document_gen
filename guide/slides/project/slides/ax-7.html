부록 A · OCR 문항 필드

문항 한 줄의 필드 (*_tasks.jsonl) (2/2)

키뜻
images모델 입력 이미지 경로 1개 (사본, 잘라낸 단어, 타일, 색 박스 그림 중 하나)
context_image이 문항을 만든 사본 페이지 이미지 (잘라낸 이미지·타일의 원래 페이지)
target정답 JSON 문자열. 글자 과제는 `{"text"}`, 박스 과제는 `{"boxes": [{"bbox_2d", "label"}]}`
confidence정답 단어들의 사내 OCR 신뢰도 중 최솟값 (평가에서 0.95 이상/미만으로 나눠 봄)
masked_words(spotting만) 신뢰도가 낮아 타일에서 배경색으로 지우고 정답에서 뺀 단어 수
size정답 박스 높이 구간 `small`(<12) / `medium`(<25) / `large` (0~1000 좌표 기준, 평가에서 나눠 봄)
