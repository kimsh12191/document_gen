과제 8종: 글자 → 위치, 위치 → 글자

과제입력출력배우는 것
crop_ocr단어를 잘라낸 이미지글자노이즈 속 인식
bbox_ocr페이지 + 단어 박스글자좌표 → 내용
grounding페이지 + 글자그 글자의 모든 박스 (없으면 [])내용 → 좌표
region_ocr페이지 + 여러 단어 영역영역 안 글자 (줄 단위)영역과 읽는 순서
spotting페이지 타일 (단어 40개 이하)모든 글자 + 박스문서 전체 배치
relation페이지 + 기준 글자 + 방향바로 옆 글자와 박스항목명 → 값 위치
marked_ocr색 박스를 그린 페이지 + 색박스 안 글자표시한 곳 → 내용
marked_box같은 이미지 + 색그린 박스 좌표 + 글자표시한 곳 → 좌표

박스 답 형식: [{"bbox_2d": [x1, y1, x2, y2], "label": "글자"}] · grounding의 약 10%는 없는 글자를 묻는 문항 · 질문은 한국어·영어 두 문장

OCR 과제 · 질문 문장 전체: docgen/bench/ocr_tasks.py (PROMPTS)

marked 과제는 이미지에 직접 색 박스를 그려 넣어 만듭니다. 그린 박스의 좌표는 OCR 박스가 아니라 우리가 그린 사각형이라 정답이 정확합니다. 좌표 숫자와 이미지 위치를 연결해 주는 보조 과제입니다.
