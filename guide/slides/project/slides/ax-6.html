부록 A · OCR 문항 필드

문항 한 줄의 필드 (*_tasks.jsonl) (1/2)

키뜻
id문항 ID: `<페이지 ID>_v<사본 번호>_<과제>_<순번>`
task과제 이름
document_id원본 문서 ID (manifest). 학습·검증·벤치마크는 이 단위로 나뉜다
page_id원본 페이지 ID (manifest)
splittrain / val / benchmark
view입력 이미지 종류: `clean` 깨끗한 사본, `aug` 노이즈 사본
view_id이 문항이 쓴 사본 이미지의 ID
view_ops노이즈 사본에 적용한 변환 목록 (예: `scale0.760` 축소, `blur` 흐림, `rotate…`, `jpeg…`). 깨끗한 사본은 []
reference_type정답의 출처. `ocr_pseudo_unreviewed` = 사내 OCR 결과, 사람 검수 없음
messages모델에게 보내는 질문 (user 한 턴). `<image>` 자리에 images[0]가 들어간다
