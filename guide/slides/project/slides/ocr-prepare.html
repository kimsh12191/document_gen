OCR · 데이터 구조 · OCR 준비

OCR 준비: manifest 한 장 → 문항 전부

1 문서 단위 분리

학습 문서 5% → 검증, 10% → 벤치마크 (split 있으면 유지)

2 이미지 점검

EXIF 회전 보정, 같은 이미지가 분리를 넘으면 중단

3 OCR 읽기

저장된 JSON 매핑, 없으면 사내 OCR 호출 + 캐시

4 단어 거르기

학습은 신뢰도 0.95 미만·깨진 글자 제외 (벤치마크는 유지)

5 사본 만들기

2300×1600 이하 clean 1장 + 노이즈 2장, 박스도 같이 변환

6 문항 만들기

사본마다 과제 8종 (grounding 8, bbox 8, relation 6 …)

7 과제 형식

tasks/<과제>.jsonl + meta.json, 문항마다 meta.split

8 옛 형식 사본

train_sft · train_grpo · *_tasks.jsonl (같은 문항)

9 DONE.json

맨 마지막에 기록, 실패한 폴더는 학습에 안 쓰임

python -m docgen.bench.ocr_prepare ocr_config.json # 1000장 약 0.5~1시간 · studio ④·⑥도 같은 코드

OCR 과제

OCR 준비가 OCR 데이터 만들기의 전부입니다. 사내 OCR 결과 JSON을 이미 갖고 있으면 OCR을 다시 부르지 않고 그 JSON을 매핑만 합니다. 원본 이미지에서 OCR한 박스를, 학습용으로 줄이고 노이즈를 넣은 사본에도 같은 기하 변환으로 옮기는 게 핵심입니다. 자르기에 걸려 잘린 단어는 cut으로 표시해서 어떤 문항에도 쓰지 않습니다. output_dir이 이미 있으면 덮어쓰지 않으니 설정을 바꾸면 새 이름으로 만듭니다.
