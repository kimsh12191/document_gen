1부 OCR · 데이터 구조 · prepare

prepare: manifest 한 장 → 학습 데이터 전부

1 문서 단위 분리

학습 문서 5% → 검증, 10% → 벤치마크 (split 있으면 유지)

2 이미지 점검

EXIF 회전 보정, 같은 이미지가 분리를 넘으면 중단

3 OCR 읽기

저장된 JSON 매핑, 없으면 사내 OCR 호출 + 캐시

4 단어 거르기

학습은 신뢰도 0.95 미만·깨진 글자 제외 (벤치마크는 유지)

5 사본 만들기

2300×1600 이하 clean 1장 + 노이즈 2장, 박스도 같이 변환

6 문항 만들기

사본마다 과제 8종 (grounding 8, bbox 8, relation 6 …)

7 SFT 뽑기

과제 비율로 최대 3만, 같은 이미지 질문 8개를 한 대화로

8 GRPO 문제 풀

grounding · spotting · relation 학습 문항 + 보상용 target

9 DONE.json

맨 마지막에 기록, 실패한 폴더는 학습에 안 쓰임

python -m bank_ocr prepare --config config.json # run_pipeline 첫 단계 · 1000장 약 0.5~1시간

1부 OCR 학습

prepare가 1부 데이터 준비의 전부입니다. 사내 OCR 결과 JSON을 이미 갖고 있으면 OCR을 다시 부르지 않고 그 JSON을 매핑만 합니다. 원본 이미지에서 OCR한 박스를, 학습용으로 줄이고 노이즈를 넣은 사본에도 같은 기하 변환으로 옮기는 게 핵심입니다. 자르기에 걸려 잘린 단어는 cut으로 표시해서 어떤 문항에도 쓰지 않습니다. output_dir이 이미 있으면 덮어쓰지 않으니 설정을 바꾸면 새 이름으로 만듭니다.
