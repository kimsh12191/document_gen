결과 보기 · studio ⑥ 데이터셋

답의 박스를 이미지 위에 그려 본다

python -m studio # docgen 도커 · 브라우저 http://localhost:8765 (SSH 터널)

문항 탭

  • 과제를 고르면 그림·질문·정답
  • 정답(초록) · 질문 영역(파랑 점선) · 모델 답 박스 겹쳐 보기
  • OCR · 문서 이해 · 업무 16과제 모두
  • 문항 안 글자 검색

모델 답 탭

  • runs/<실험>/ 을 붙이면 채점
  • docgen.bench.evaluate (= GRPO 보상)로 채점
  • 명령줄 보고서와 같은 숫자
  • 학습 점수 파일도 보기

문항 점수

  • 문항마다 모델별 점수
  • 첫 답 점수 낮은 것부터
  • GPU 없이, 학습 중에도 사용 가능

결과 보기 · 사용법: studio/README.md (⑥ 데이터셋)

studio ⑥의 문항 탭은 모델이 실제로 어디를 보고 답했는지를 눈으로 확인하는 곳입니다. 예전 OCR·은행 업무 viewer 둘을 대신합니다. 점수표만으로는 박스가 조금씩 밀리는지, 특정 글씨체에서 틀리는지 알기 어렵습니다.
