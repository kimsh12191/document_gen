실제 데이터로 확장 · 은행 업무

실제 서류도 같은 폴더 구조로 만들면 된다

real_bench/ ← 평가 세트
meta.json {"split": "test", …}
images/
C0001/loan_application_p1.png
C0001/withholding_receipt_p1.png
tasks/
doc_check.jsonl
cross_check.jsonl
review.jsonl kie.jsonl …

real_train/ ← 학습 데이터
meta.json {"split": "train", …}
images/ tasks/ (같은 구조)
(swift/ 는 없어도 됨: 섞기가 tasks/ 로 만듦)

파이프라인에 연결

"data": {
"benchmark": ["/data/real_bench"],
"train": ["/data/bank_train",
"/data/real_train"]}

  • meta.json의 split으로 평가(test)·학습(train)을 구분
  • tasks/는 과제별 문항 파일, 한 줄 = 한 문항
  • 학습 폴더는 합성 데이터와 함께 여러 개 나열 가능
  • 평가만 실제로 바꾸고 학습은 합성 그대로도 가능

실제 데이터로 확장 · 지금 파이프라인 코드를 바꾸지 않고 연결되는 구조

은행 업무 과제는 아직 합성 데이터만 썼지만, prepare는 폴더 구조만 맞으면 어디서 온 데이터인지 상관하지 않습니다. 가장 현실적인 첫 단계는 실제 서류 묶음 수십 개로 평가 세트만 만드는 것입니다. 학습은 합성 데이터 그대로 두고, 실제 평가 세트로 진짜 성능을 재는 겁니다.
