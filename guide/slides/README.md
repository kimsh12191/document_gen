# 발표 자료: 은행 서류 VLM 프로젝트 소개

팀 내부 개발자용 소개 슬라이드입니다. 1부 OCR 학습, 2부 은행 업무 학습, 실제 데이터로 확장하는 구조, 현재 상태를 다룹니다.

- **보기:** `index.html`을 브라우저로 엽니다. 슬라이드 아래에 발표자 노트가 함께 나옵니다. 글꼴은 인터넷이 될 때 Google Fonts에서 받고, 안 되면 기본 글꼴로 보입니다.
- **원본:** `project/deck.json`(순서·제목)과 `project/slides/<id>.html`(슬라이드 한 장씩). 웹 슬라이드 도구에서 만든 파일 그대로입니다.
- **다시 만들기:** 슬라이드 원본을 고친 뒤 `python guide/slides/build_html.py`를 실행하면 `index.html`이 갱신됩니다.
- 같은 내용의 문서판은 [../overview.md](../overview.md)입니다.
