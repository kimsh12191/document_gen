1부 OCR · 컨셉

사람 검수 없이, 사내 OCR을 선생님으로

무엇을 배우나

  • 글자 내용 ↔ 위치(박스 좌표) 양방향
  • 스캔·촬영 노이즈에 강하게
  • 좌표: 이미지 기준 0~1000 정수 [x1, y1, x2, y2]

정답은 어디서

  • 내부망 실제 서류 이미지를 사내 OCR에 돌린 결과
  • 사람이 검수하지 않은 의사정답
  • 점수 = 사내 OCR과 얼마나 같은지

지키는 원칙

  • 정답이 불완전한 영역은 버림
  • 신뢰도 낮은 단어·잘린 단어가 걸친 영역은 문항으로 안 만듦
  • 읽는 순서는 박스 위치로 정함

한계: 사내 OCR이 틀린 곳은 정답도 틀리고, OCR이 놓친 글자는 빠뜨리도록 배울 수 있다 → 노이즈 많은 페이지로 사람 검수 정답셋이 있으면 좋다

1부 OCR · 학습 방법

SFT로 형식과 읽기, GRPO로 박스 정밀도

SFT

  • LoRA rank 32 · 비전 인코더까지 전부 학습
  • 최대 3만 문항 · lr 1e-4 · 길이 10,240토큰
  • 같은 이미지 질문 8개를 한 대화로 묶어 이미지는 한 번만 처리

GRPO

  • 대상: grounding · spotting · relation (답이 여러 개라 점수 차이가 생김)
  • 후보 6000을 SFT로 풀고 보상 0.9 미만을 절반 섞어 2000문제
  • lr 5e-6, beta 0.04, 한 문제에 답 8개 (40GB는 4개)

GRPO 보상

박스 = 2 × Σ 짝별 점수 / (예측 박스 수 + 정답 박스 수), 짝별 = min(1, IoU / 0.8)
글자 = 0.7 × 문자 유사도 + 0.3 × 숫자 유사도 · 정답 []에는 [] 일 때 1 · 형식 오류 0

박스 남발 꼼수 차단 · IoU 0.8 이상 만점 (정답 박스 잡음까지 배우지 않게)

1부 OCR 학습 · 설계 상세: training/docs/DESIGN.md

지켜야 할 것

  • 문서 ID: 같은 문서의 쪽은 같은 ID. 파일명 규칙이 없으면 manifest를 직접 작성
  • OCR JSON: 사내 OCR 응답 그대로 (success · basicData · vertices). 다른 형식은 config의 mapping으로 키 지정
  • 같은 픽셀: OCR을 돌린 이미지 파일 그대로 (PDF는 쪽별 이미지로)
  • OCR JSON이 없으면: 사내 OCR 서버를 띄우고 (GPU_ID=7 SERVER_PORT=30107 python server.py) INTERNAL_OCR_BASE_URL로 연결 → prepare가 호출
  • OCR 버전: ocr_revision을 바꾸면 캐시도 새로
  • 벤치마크: benchmark_fraction 10%로 자동 분리, 또는 split: benchmark 지정

2부 은행 업무 · 학습 방법

평가 채점기가 곧 GRPO 보상

prepare

  • 이미지 토큰: 문항당 합계 12,000 이하 (평가도 동일)
  • SFT 2만 문항, 과제 비율대로
  • 고객 20%는 GRPO용으로 분리
  • 1부 OCR 데이터 3000개 섞기
  • 검사: 고객 겹침, 정답 = 만점

SFT

  • 1부 결과 모델(병합본)에 새 LoRA rank 32
  • 1 epoch, lr 1e-4, 길이 16,384토큰
  • 같은 이미지 질문은 한 대화로 묶음
  • 40GB: 비전 인코더 고정 + zero3

GRPO

  • 후보 3000을 SFT로 풀고 보상 0.9 미만 절반 섞어 1000문제
  • 대조·질의·구비·추출, 이미지 4장 이하
  • lr 5e-6, 답 8개 (40GB는 4개)

보상 = docgen 벤치마크 채점기 그대로 + 부분 점수

서류 구비: 0.5 × 완전 일치 + 0.5 × F1 · 서류 대조 변조: 0.5 × (불일치라고 함) + 0.5 × (서류·값까지 짚음) · 그 외: 주 지표

0 아니면 1이면 답 8개가 같은 점수 → 배울 게 없음. 정답이 분명해서 1부 의사정답보다 신호가 깨끗함

충분히 모이면 split: train 폴더를 data.train에 추가

prepare가 대신 확인하는 것

  • 학습·평가에 같은 고객 묶음 ID가 있으면 중단
  • answer를 그대로 넣으면 만점인지 (정답·eval 오류 탐지)
  • 이미지 크기는 학습과 같은 규칙으로 자동 축소
