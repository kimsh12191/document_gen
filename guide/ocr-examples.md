# OCR 예시를 보는 방법

Studio 왼쪽 메뉴의 **OCR 예시**에서 데이터셋을 만들거나 등록하지 않고 8개 OCR 과제를 확인할 수 있습니다. 과제를 선택하면 **입력 이미지 → 질문 → 모델이 출력해야 하는 답 → 채점 기준**을 함께 보여 줍니다.

| 과제 | 입력·질문 | 확인할 답 |
|---|---|---|
| `crop_ocr` | 잘라낸 글자 이미지 | 읽은 문자열 |
| `bbox_ocr` | 페이지 이미지와 지정 박스 | 박스 안 문자열 |
| `grounding` | 페이지 이미지와 찾을 글자 | 해당 글자의 모든 위치 |
| `region_ocr` | 페이지 이미지와 지정 영역 | 영역 안 글자를 읽기 순서대로 |
| `spotting` | 이미지의 모든 글자 찾기 | 글자와 위치 목록 |
| `relation` | 기준 글자와 방향 | 이웃 글자와 위치 |
| `marked_ocr` | 색 박스로 표시한 이미지 | 지정 색 박스 안 글자 |
| `marked_box` | 색 박스로 표시한 이미지 | 박스의 글자와 위치 |

위치는 `bbox_2d: [x1, y1, x2, y2]`이며 입력 이미지 기준 0~1000 상대 좌표입니다. 상세 질문·정답·이미지는 [실제 과제 예시의 OCR 부분](tasks.md#ocr-과제)에 있습니다. Studio 화면도 이 파일과 같은 이미지에서 예시를 읽으므로 별도의 예시 사본을 관리하지 않습니다.

## 입력과 정답 표시의 차이

- 왼쪽의 **모델에 주는 입력 이미지**가 실제 입력입니다. 클릭하면 크게 볼 수 있습니다.
- **정답 위치·질문 영역 표시 보기**를 펼치면 초록 정답 박스와 파란 질문 영역을 표시한 설명용 이미지를 볼 수 있습니다. 이 추가 표시는 모델 입력이 아닙니다.
- 색 박스를 읽는 `marked_ocr`·`marked_box`에서는 원래 색 박스 자체가 질문의 일부이므로 입력 이미지에도 포함됩니다.
- 오른쪽의 **모델이 출력해야 하는 답**과 데이터의 **정답 target**은 표현이 다를 수 있습니다. 예를 들어 target은 `{"text":"글자"}`를 저장하지만 모델은 `글자`만 답합니다. 둘을 구분해서 표시합니다.

## 예시 출처와 내 데이터 확인

현재 화면은 가이드에 포함된 **합성 예시 한 건씩**을 보여 줍니다. 가상 서류의 라벨을 OCR 응답 형식으로 바꾼 뒤 실제 OCR 준비 코드로 만들었습니다. 설명용 이미지는 긴 변 1000px 이하로 줄인 사본입니다. 원본 문항의 `reference_type` 등 메타데이터는 그대로 보여 주며, 실제 고객 데이터나 현재 연구 데이터셋의 결과를 뜻하지 않습니다.

내가 생성하거나 가져온 OCR 데이터의 실제 문항은 **데이터셋 → 해당 데이터셋 → 문항**에서 확인합니다. 합성 데이터는 [생성 가능 범위](research-agent.md)와 [원격 생성](remote-build.md), 실제 서류 이미지는 [OCR 준비 가이드](ocr_prepare.md)를 따릅니다.

Research agent는 `/api/ocr-examples`에서 화면과 같은 8과제의 질문·정답·이미지 URL을 JSON으로 조회할 수 있습니다. URL은 Studio 주소를 기준으로 해석합니다. 예시를 다시 만들 때는 [문서 갱신 절차](README.md#문서와-카탈로그-갱신)를 사용합니다.
