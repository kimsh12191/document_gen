# 서식 변형 — corporate

법인 서류(법인등기부·정관·주주명부·재무제표·법인인감증명서·이사회/주주총회 의사록·위임장)의 여러 쪽(heavy)·특수 상황(special) 목록.
법인의 등기 이력과 주주 구성은 **프로필 단위**(`docgen/docs/corporate.py` 의 `_facts(p)` / `_cap_table`, seed `corp-facts:{p.seed}:…`)로 정한다.
그래서 같은 고객의 등기부·정관·주주명부·재무제표·의사록 내용이 서로 맞는다(상호 변경일 = 정관 개정일, 자기주식은 주총 의결권에서 빠짐, 우선주는 등기부·정관·재무상태표에 모두 나옴).
프로필 값(`p.shareholders`, `p.directors`)은 바꾸지 않는다. 주주가 많아지는 경우에도 대표이사 주식수와 지분 25% 이상 주주는 그대로 두어, 실제소유자 확인 서식과 어긋나지 않게 했다.
heavy()/special() 을 그대로 쓰므로 `DOCGEN_HEAVY`, `DOCGEN_SPECIAL` 강제 설정도 똑같이 적용된다.

## 메모
- 말소 표시는 `_Row(dict).struck` 속성으로만 넘긴다(정답 값 아님). 말소된 기록의 글자(옛 상호·주소·「사임」「퇴임」「폐지」 등)는 화면에 보이므로 정답에 들어간다.
- 화면 구성 선택(정관 전문 여부, 날인 확률)은 `_Doc(dict)` 속성으로 넘겨 「생성했지만 표시하지 않은 값」 경고가 나지 않게 했다.
- 법인인감증명서·위임장은 실제로 한 장짜리라 여러 쪽 경우를 넣지 않았다.
- 주주명부 표는 `table-layout:fixed` 와 머리글 칸 너비로 열 너비를 정해, 다음 쪽에 이어지는 표(colgroup 없이 복사됨)도 열이 같다. 소액주주의 비고 칸은 빈 칸(null)이라 check 에서 「빈 값 필드」 WARN 이 나온다(의도한 것).
- 등기부의 말소사항 포함 표기(밑줄/취소선 색, 임원 사임 줄 위치, 「공동으로 회사를 대표」 문구), 법인인감증명서 인터넷 발급 바닥글, 공증 인증문 문구는 실제 서식을 바탕으로 한 추정이다.
