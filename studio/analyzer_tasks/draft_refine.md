## 할 일

1. 겹침 그림과 숫자를 보고 원본과 다른 점을 중요한 순서로 많아야 8개 적는다 (어느 덩어리의 무엇이 얼마나).
2. 그 차이를 고치는 수정만 한다. 맞는 부분은 건드리지 않는다. 숫자가 있으면 숫자대로 고친다 (눈대중으로 크게 바꾸지 않는다).
3. 빠진 고정 문구·선·칸이 있으면 원본대로 더한다. 칸 ID 는 그대로 둔다. 칸을 더하거나 빼면 SLOTS 에 칸 목록 전체를 다시 쓴다.

## 답 형식

아래 구획만 쓴다. 수정은 찾아 바꾸기 묶음으로: SEARCH 에는 지금 템플릿에 **정확히 한 번** 나오는 몇 줄을 그대로 옮기고, REPLACE 에 바꾼 줄을 쓴다.

```
<<<DIFF>>>
- 1번 표 행 높이가 원본보다 3px 큼 (가로선이 행마다 3px 씩 벌어짐)
- …
<<<EDITS>>>
<<<<<<< SEARCH
table.f tr { height: 24px; }
=======
table.f tr { height: 21px; }
>>>>>>> REPLACE
<<<<<<< SEARCH
…
=======
…
>>>>>>> REPLACE
<<<END>>>
```

- 고칠 곳이 많아 전체를 다시 쓰는 편이 낫다면 EDITS 대신 `<<<TEMPLATE>>>` 구획에 템플릿 전체를 쓴다.
- 칸을 바꿨으면 `<<<SLOTS>>>` 구획에 칸 목록 전체 (처음과 같은 꼴).
- 더 고칠 것이 없으면 `<<<DONE>>>` 만 쓴다.
